用 GitHub Pages 搭建个人博客

by Veritas / 教程

GitHub Pages 是搭建个人博客最经济的方式之一：免费、稳定、无需服务器。只需一个命名为 <username>.github.io 的仓库，把静态文件推送到 main 分支根目录，GitHub 就会自动为你生成一个可访问的网站。

本文记录了我从模板出发搭建这个博客的过程：把模板文件放到仓库根目录、保留相对路径以便日后迁移、用 mailto 让联系表单在纯静态环境下也能工作。写下这些，既是对自己的一次梳理，也希望能帮到同样想拥有自己一片小天地的你。
